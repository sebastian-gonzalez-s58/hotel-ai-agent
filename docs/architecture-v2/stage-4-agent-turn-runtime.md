# Stage 4: Agent turn runtime

The V2 agent is a reconstructible planner. `POST /internal/v2/turns` receives the complete hotel-owned context and returns either guest message drafts or proposed domain tool calls.

## Safety boundary

- The agent never calls FluxNova or writes hotel state.
- Spring chooses the allowed tool list and executes accepted calls.
- Every operation, task and evidence ID is checked against the supplied turn context.
- A measured OpenAI usage block replaces any usage data generated by the model.
- Immediate retries use `agentTurnId` as the idempotency key. The in-memory cache is only a retry optimization; Spring remains the durable source of truth.

The endpoint is available only when `AGENT_RUNTIME_MODE` is `shadow` or `v2`. Legacy hotel endpoints remain unchanged.
